# 📊 Sales Performance Dashboard

This project analyzes sales data to identify trends, patterns, and business insights using Python.

## 🚀 Live Demo
👉 https://my-project-ywva.onrender.com

## 📊 Problem Statement
Businesses need to understand their sales performance to make better strategic decisions.

This project aims to:
- Analyze revenue trends over time
- Identify top-performing products
- Support data-driven decisions

## 🛠️ Technologies Used
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## 📈 Key Insights
- Sales show consistent growth over time
- A small number of products generate most revenue
- Seasonal patterns can be observed
